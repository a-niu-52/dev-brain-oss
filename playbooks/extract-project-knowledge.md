# 提炼项目知识

## 输入

已完成任务、代码差异、命令输出、测试结果、项目范围和用户反馈。

## 步骤

1. 收集可复核证据，删除客户、账号、密钥、内部地址和绝对路径。
2. 判断内容属于 Context、Core、Profile、Projects、Prompt、Skill、Playbook 或 Reference。
3. 写入 `inbox/`，记录适用范围、例外、核验日期和不能推导出的结论。
4. 人工确认后移动到正式目录；失效或被替代的内容移动到 `archive/`，记录归档原因和替代文档。
5. 运行内容和敏感信息校验。

## 验证

- 其他人能根据证据复核结论。
- 文档不含敏感信息和绝对路径。
- 正式知识没有覆盖项目专属例外。
- 归档内容不被自动入口引用。

## 停止条件

- 只有一次观察且没有重复证据。
- 适用范围无法界定。
- 无法完成脱敏或存在规则冲突。
