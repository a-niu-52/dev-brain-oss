# 大需求单文件记录模板

本文件是一项 Large 需求的唯一过程记录，集中保存需求卡、深入分析、方案、任务、验证、审查、交付和暂停恢复信息。单文件约束针对过程文档，不限制实现所需的源代码文件数量。按任务填写适用章节；不要为每种模板另建文件。`change-design.md`、`task-plan.md`、`verification-report.md`、`session-handoff.md` 可作章节写法参考。

## 使用条件与文件规则

- 按 `core/task-routing.md` 在 Large、高风险或用户要求深入分析时使用。
- 只有用户要求保存、项目规则要求留档或任务需跨会话时，才将本模板复制到目标项目；否则在对话中按本结构组织，不创建文件。
- 需要留档时，只创建一份 Markdown 过程记录；除用户明确要求或项目规则硬性要求外，不拆分需求、设计、任务、验证和审查文档。
- 事实未知时标为“待核实”并写明核实方式，不把假设写成现状。不适用项写“不适用”。
