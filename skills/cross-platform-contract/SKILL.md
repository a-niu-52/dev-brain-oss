# Cross Platform Contract

1. 以 H5 或调用方协议为基线，读取适配层和每个平台实现。
2. 逐平台核对方法名、参数类型、返回值、回调、错误、超时和降级。
3. 通过不启动 App/设备的单元或契约测试检查成功、失败、取消、重复调用和无原生能力场景。
4. 输出协议差异表、受影响调用方和最小验证矩阵。
5. 不因为一个平台通过就声称跨平台通过。
6. 不使用真机、模拟器、仿真器或设备形态模拟；依赖设备运行时的行为明确标为未验证。
