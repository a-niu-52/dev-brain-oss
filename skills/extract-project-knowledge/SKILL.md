# Extract Project Knowledge

1. 收集本次任务的代码、命令、测试和用户反馈证据。
2. 删除客户名、账号、密钥、内部地址、绝对路径和聊天原文。
3. 标注适用范围、例外、最后核验日期和不能推导出的结论。
4. 写入候选区，等待人工确认后再提升到正式知识目录。
5. 如果项目规则和候选经验冲突，保留冲突说明，不静默覆盖。
6. 不自动修改项目规则，不自动执行 `git push`。
