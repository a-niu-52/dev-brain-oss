# Dev Brain 全局规则

- 默认使用中文交流；复杂任务先读取规则、设计和计划。
- 开始任务先检查项目规则、Git 状态、当前分支、远程和真实构建配置。
- 项目级规则优先于个人 Profile；不根据技术栈名称猜测命令。
- 保护已有本地修改，不自动 stash、reset、覆盖、迁移或重建项目。
- 未经用户明确确认，不执行 `git push`。
- 远程操作失败时保留现场，报告当前分支、状态、未推送提交和远程地址。
- 修改完成后只根据新鲜验证输出报告结果。
- 可按需读取 `~/.dev-brain/repo/context/`、`core/`、`profiles/`、`projects/`、`prompts/`、`references/` 和 `playbooks/`。
- 新经验先进入 `inbox/`；历史资料默认不主动读取。
