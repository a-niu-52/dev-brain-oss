# 项目接入 Prompt

- 适用场景：刚进入项目，尚未了解规则和真实命令。
- 需要填写的输入：当前项目目录和本次任务目标。
- 可复制提示词：

```text
先读取当前目录及父级生效的项目规则，不修改任何文件。记录 Git 状态、当前分支、远程和未推送提交；再读取真实构建清单、架构文档和知识入口，识别技术栈与适用 Profile。输出项目入口、目标分支、风险、验证命令和仍需确认的问题，然后等待我的具体开发任务。
```

- 预期输出：入口清单、技术栈、分支策略、风险、验证矩阵和待确认问题。
- 对应 Skill：`project-onboarding`
- 对应 Playbook：`start-new-project.md`
