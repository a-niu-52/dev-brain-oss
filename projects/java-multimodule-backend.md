# Java 多模块后端项目知识

- 项目标识：java-multimodule-backend
- 来源类型：近期活跃 Java 后端项目的脱敏观察
- 技术栈：Java 8、Spring Boot、Maven 多模块、MyBatis
- 适用范围：模块级接口、事务、持久层和服务间调用
- 最后核验日期：2026-09-20
- 脱敏状态：已脱敏

## 规则入口

先读取根 `pom.xml`、目标模块 `pom.xml`、项目规则文件、启动说明和测试配置。

## 目录与关键调用链

- Controller → Service → Mapper/Repository → 数据库或外部服务。
- 多模块公共 DTO、枚举和异常会影响多个调用方。
- 事务边界必须和数据库写入及外部副作用一起核对。

## 真实验证命令

确认模块后优先执行 `mvn test -pl <module> -am`，再按项目配置补充集成测试。

## 高风险区域

事务、退款或金额、批量状态流转、MyBatis 映射、跨模块依赖和默认跳过测试配置。

## 已验证约定

- 不凭模块名称猜测启动命令。
- 先确认 Maven profile 是否会跳过测试。
