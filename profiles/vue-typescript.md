# Vue / TypeScript Profile

## 识别

先读取 `package.json` 的实际 scripts 和锁文件，不猜测包管理器或启动命令。

## 验证顺序

1. 相关单测和组件测试。
2. `vue-tsc --noEmit`。
3. ESLint 或项目已有静态检查。
4. 需要时运行构建。
5. 涉及跨页面主流程、登录、路由或真实提交时运行对应 Playwright 测试。

## 约定

- 单测沿用项目现有 colocated `*.spec.ts` 方式，不强制搬迁目录。
- 路由、组件、服务和联调规则以项目级知识卡片为准。
- 改动公共类型时同时检查调用方和接口返回兼容性。
